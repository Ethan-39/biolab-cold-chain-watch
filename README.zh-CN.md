# BioLab Cold-Chain Watch｜实验室冷链监测

这是一个规则告警教学项目，用于回放一台**虚构冷藏设备**的温度与用电仿真数据。它会标出温度越界、读数缺失和异常用电，并提示人工核查；它不是机器学习模型，也不会连接或控制设备。

![BioLab Cold-Chain Watch 仪表板](assets/dashboard-desktop.png)

## 怎么运行

安装 Python 3.10 或以上版本后，在本目录运行：

```powershell
python cold_chain_watch.py
python -m unittest discover -s tests -v
```

也可在 Windows 双击 `run.cmd`。脚本会生成仿真遥测 CSV、告警回放 CSV、测试指标 JSON 和 `dashboard.html`。

## 固定演示结果

脚本模拟 14 天、每 15 分钟一个读数，前 7 天作训练/参考期，后 7 天作测试期；测试期中注入温度异常、读数缺失和断电三个场景。固定生成场景的点级 precision 和 recall 均为 1.00，因为这些注入异常刻意设计得容易识别。

这只说明规则在这份人工构造的数据上按预期触发，不是现实准确率，也不能说明实际实验室适用性。

## 安全与生物队友可以做什么

界面上的 2–8 °C 只是为了验证软件逻辑的**占位阈值**，不是任何样本要求、实验室 SOP 或设备标准。真实边界需由样本要求、设备说明书、实验室 SOP 和负责人员确定。本项目无法评估样本活性或合规性，不会建议改设定温度或关闭设备。能耗数据不代表节能或减碳。

生物科学队友可以使用 [`BIOLOGIST_REVIEW.md`](BIOLOGIST_REVIEW.md) 讨论场景是否易懂、哪些告警可能误报/漏报、实际实验室还缺哪些约束；这属于场景审阅，不等于批准真实部署。

## 术语备注

- **遥测（telemetry）**：传感器或设备周期性产生的测量读数。
- **稳健范围**：用中位数和中位数绝对偏差估算参考区间，减少少数极端值对阈值的影响。
- **Precision（精确率）**：本项目的告警中，命中注入事件的比例。
- **Recall（召回率）**：注入的异常读数中，被规则告警捕捉的比例。

这些指标只描述固定仿真场景。

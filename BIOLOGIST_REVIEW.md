# Scenario review worksheet

This worksheet is for a teammate to review the **fictional demo scenarios**, not to approve the software for laboratory operations.

For each scenario, discuss:

1. Is the scenario understandable to a biology student? What context is missing?
2. Would a person know what to check after the alert? Keep the response at manual verification; do not suggest changing settings or switching off equipment.
3. Which event could create a false alarm? Which event could be missed?
4. Which real constraints would need confirmation from the lab, equipment documentation, and responsible staff before any real deployment?
5. What evidence would be needed before claiming an energy or carbon benefit?

The demo's 2–8 °C range is only a placeholder used to test software behavior. Do not substitute it for a lab protocol, sample requirement, manufacturer instruction, or local policy.
